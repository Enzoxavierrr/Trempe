# Trempe

Projeto de estudo: restaurante com foco em fogo lento, cardápio sazonal e reservas.

Arquitetura: **SDD (Spec-Driven Development)** por fora, **DDD + Clean Architecture** por dentro.

## Stack

- **Front**: React + Vite + TypeScript
- **Back**: .NET 8 + Minimal APIs + Dapper + Postgres
- **Testes**: xUnit

## Estrutura

- `specs/` — specs funcionais (SDD)
- `plans/` — planos técnicos derivados
- `tasks/` — checklist executável
- `design/` — mockups de referência (landing, checkout)
- `apps/web/` — front React
- `src/` — back .NET
- `tests/` — testes do back
